OAuth Test Console

Sign in with Google, Facebook and GitHub against your backend, or generate the raw provider token and use it from Postman.

Checking backend
This page was opened from a file. Google, Facebook and GitHub all need a real origin, so serve it instead: run python3 -m http.server 3000 in this folder and open http://localhost:3000/oauth-test.html.
Configuration

Public identifiers only. Never paste a client secret or app secret here; those stay in the backend .env.
